# Shaheer Khan — AI Engineer Portfolio

Static portfolio prepared for Vercel.

## Deploy with Vercel

1. Push this folder to a GitHub repository, then import that repository in Vercel.
2. Set **Root Directory** to `site` if this folder lives inside a larger repository.
3. Keep **Framework Preset** as `Other` and deploy. `vercel.json` already points Vercel to `dist`.

You can also deploy from this folder with the Vercel CLI using `vercel --prod`.
